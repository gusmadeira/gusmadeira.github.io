GUSTAVO MADEIRA — WEBSITE REDESIGN (NOV 2026)

This is a ready-to-publish static website for https://gusmadeira.github.io/.
No build step or third-party dependencies beyond optional web fonts.

INSTALL
1. Extract the ZIP.
2. Replace the CONTENTS of your local repository (keeping its hidden .git directory), rather than nesting the extracted folder.
3. From inside the repository, run:
   git add -A
   git commit -m "Redesign personal website"
   git push origin main

IMPORTANT: git add -A tracks deletions of unused old files.

GODS LINKS
The GODS link targets https://godsastronomy.github.io/gods/
Research Data entries 03 and 04 target data3.html and data4.html in GODS.
The GODS repository must deploy these pages; as of this redesign, the public repository did not yet contain these two files.

The legacy local gods.html, data3.html and data4.html are small redirects for old bookmarks.
The unfinished teaching handbook was removed, along with its PDF.
Scientific descriptions, publication links and contact details were preserved.
